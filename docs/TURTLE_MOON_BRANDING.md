# Turtle Moon attribution on About

Reviewed 2026-09-12. The owner identified **Turtle Moon** as Bitcoin Browser's creator and supplied **https://turtlemoon.io/** as its website.

- Website destination: [Turtle Moon](https://turtlemoon.io/), preserved exactly as supplied, normalized to HTTPS.
- Current logo source: the owner-specified local **`turtlemoon-marketing-2`** project serving `localhost:3000`. Its `Header.tsx` and `Footer.tsx` use the turtle/crescent vector in `src/components/Brand.tsx`; the matching self-contained icon is `src/app/icon.svg`.
- Bundled image: [turtle-moon.svg](../src/renderer/assets/turtle-moon.svg) is copied unchanged from that **100 × 100 viewBox SVG icon**, including its dark-green mark and rounded cream background. Its two paths and eye geometry match the live site's `Brand.tsx`; the icon provides the source site's fixed brand colors without depending on its CSS. [turtle-moon.js](../src/renderer/assets/turtle-moon.js) points only to this local asset. The image stays legible in either app theme, uses smooth vector rendering instead of pixel-art scaling, and leaves the textual credit intact if loading fails.
- Superseded asset: the earlier 25,126-byte pixel-art PNG from the public promo site is no longer bundled or displayed. The local site's unrelated starter `public/logo.svg`, older PNG references, and tools-product wrench/hammer mark are not used.

The image identifies Turtle Moon at the project owner's request. The browser copies the selected local project's existing vector asset; it does not generate or redraw a new mark, substitute a Bitcoin protocol logo, or claim that the mark has been relicensed under this repository's MIT license. The mark remains its owner's branding; no broader trademark or promotional rights grant is inferred. The source marketing project is read-only in this change.

About loads no external website, script, tracking pixel or remote image, and does not contact localhost. The SVG is a static local image containing only its vector shapes, with no scripts, event handlers, external references or embedded HTML. The visible website link passes through the existing navigation parser and main-process **Leave Bitcoin Browser?** confirmation. Cancellation leaves About in place; confirmed navigation opens the user's system browser, using that browser's own privacy/network settings. Middle-click also uses the confirmation path. No wallet, credential, IPC, CSP or provider authority is added, and the future Bitcoin donation placeholder remains inactive.

During the earlier public-logo change, both the apex and `www` homepages returned HTTP 404 / Vercel `DEPLOYMENT_NOT_FOUND`. That is historical evidence, not a new availability check for this local-asset update. The public link remains `https://turtlemoon.io/`, not localhost; no permanent outage notice or automatic health check is embedded in About. Bundling the new SVG keeps its display independent of either website's availability.
